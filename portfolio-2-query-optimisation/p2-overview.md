# Portfolio 2: Query Processing and Optimisation

**Course:** MIT 8103 — Advanced Database Systems  
**Case Study:** FitCore Gym Management System  
**Database:** PostgreSQL  
**Platform:** Neon PostgreSQL

## 1. Objective

The objective of this portfolio is to investigate how PostgreSQL processes SQL queries and to explore techniques for improving query performance.

## 2. Areas of Investigation

- SQL query formulation
- Query execution plans using EXPLAIN
- Query performance analysis using EXPLAIN ANALYZE
- Indexing and its effect on query execution
- Comparison of query execution plans before and after optimisation

## 3. Method

Queries will be developed using the FitCore Gym Management System. Their execution plans will be inspected, appropriate optimisation techniques will be applied, and the results will be documented with screenshots and explanations.

## 4. Tools

- Neon PostgreSQL
- PostgreSQL SQL Editor
- GitHub
